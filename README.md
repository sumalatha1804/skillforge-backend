# SkillForge Backend

SkillForge is a personal career growth platform developed using Java and Spring Boot. It provides REST APIs for user registration, login, and career-related features.

## Technologies Used

- Java 21
- Spring Boot
- Spring Data JPA
- Hibernate
- MySQL
- REST APIs
- Maven
